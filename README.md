# fonthatch

Turn SVG text into pen-plotter-ready outlines: hatch-filled glyphs or single-stroke-font
substitutions, built on [vpype](https://github.com/abey79/vpype) and
[vsketch](https://github.com/abey79/vsketch).

The input SVG is read and written back as-is — every shape, group, gradient, and the document's
own layer structure and labels pass through untouched, compatible with files from Inkscape,
Illustrator, Affinity, and Figma. Only two things change: every original `<text>` element is
hidden in place (still real, editable text — never converted to outlines), and for each of the
source file's own top-level layers that has text, a new "`<layer>` hatched" (and, optionally,
"`<layer>` contour") layer is added right after it, independently toggleable from every other
layer. In hatch mode, each glyph keeps its true outline while its interior is filled with one of
several plotter-friendly patterns; in singleline mode, glyphs are replaced with a Hershey-style
single-stroke font. The output is a real plotter file — the same pipeline the CLI and specimen
sheets use — so what you see is what the pen draws.

(The GUI's live preview is the one exception: since it's built on vsketch/vpype, which can only
render line geometry, the on-screen preview approximates the source file — flattening non-text
content to lines and showing a glyph-outline stand-in instead of real `<text>`. Its Export button
writes the same fully-preserving output as the CLI.)

## Fill types

- **spiraling** — concentric, tangent rings that spiral inward, threaded into one continuous stroke
- **concentric** — evenly spaced contour offsets
- **lines** — straight hatch lines at a given angle
- **crosshatch** — two hatch passes crossed at an angle
- **zigzag** — one or more zigzag sweeps across the glyph
- **glyph_fill** — coverage fill tuned to follow the glyph's own shape

See [`specimens/`](specimens) for a full A3 sample sheet per fill type (every letter, digit,
and punctuation mark at two sizes), generated by [`scripts/make_specimen.py`](scripts/make_specimen.py).

## Install

Requires Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Usage

### CLI

```bash
fonthatch in.svg out.svg --mode hatch --fill-type spiraling --pen-width 0.3mm
fonthatch in.svg out.svg --mode singleline --font futural
```

Run `fonthatch --help` for the full option list (spacing, inset, angle, contour mode,
merge behavior, accented single-stroke fonts, and more).

`fonthatch` also registers as a [vpype plugin](https://vpype.readthedocs.io/en/stable/plugins.html)
(`fonthatch`/`fonthatch-write` commands) for use inside vpype pipelines.

### Interactive GUI

```bash
fonthatch-gui
```

Launches a live [vsketch](https://github.com/abey79/vsketch) viewer for tuning parameters
interactively before exporting.

### Python API

```python
from fonthatch import process_svg, HatchParams, FillType

process_svg("in.svg", "out.svg", HatchParams(fill_type=FillType.SPIRALING, pen_width=0.35))
```
